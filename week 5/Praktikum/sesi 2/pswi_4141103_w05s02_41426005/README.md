1. CARA MENJALANKAN
    Caranya dengan membuka folder proyek di VS Code, lalu buka file index.html. Setelah itu klik kanan dan pilih Open with Live Server. Nanti web yang saya buat akan otomatis terbuka di browser. 

2. PENJELASAN PERUBAHAN
    -Perubahan posisi card selamat datang,mengatur card agar sejajar dengan card lainnya.
    -Perubahan warna card menyesuaikan warna agar lebih menarik.
    -Perubahan layout Grid, menyusun card dalam 4 kolom.
    -Perubahan layout Flexbox, mengatur card agar berjajar ke samping.
    -Perubahan jarak antar card, mengatur jarak agar susunan card lebih rapi.
    -Perubahan margin dan padding, mengatur jarak antarcard dan ruang di dalam card.

4. BATASAN
    Batasan dari perubahan kode ini adalah pengembangan masih berfokus pada tampilan dan struktur dasar halaman web. Bagian kegiatan mahasiswa hanya menampilkan informasi dalam bentuk card dan belum memiliki fitur interaktif. JavaScript juga masih terbatas pada fungsi tombol salam menggunakan alert(), sehingga belum mendukung pengolahan data atau interaksi yang lebih kompleks. Selain itu, struktur HTML perlu diperbaiki karena terdapat dua elemen <main>, sedangkan pengujian responsivitas dan aksesibilitas pada berbagai perangkat masih perlu dilakukan agar halaman berfungsi secara optimal.

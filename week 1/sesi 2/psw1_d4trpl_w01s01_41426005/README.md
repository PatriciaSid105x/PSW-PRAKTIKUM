Fungsi dari HTML (Hypertext Markup Language), CSS (Cascading Style Sheets), Javascript(Js), Gitbash

1. HTML 
HTML berfungsi sebagai  pondasi atau kerangka dari sebuah bahasa pemogramanan untuk membuat sebuah website, HTML akan membuat judul, paragraf, gambar, dan masih banyak lagi tapi dalam bentuk polos.

2. CSS
CSS berfungsi sebagai bahasa yang digunakan untuk menampilkan style atau gaya pada website, yang dimana ketika sudah terdapat kerangkanya.

3. JAVASCRIPT
JAVASCRIPT berfungsi memblok kode yang digunakan untuk menjalankan tugas tertentu. Fungsi ini berguna agar kode tidak di tulis berulang ulang sehingga lebih rapi dan efisien.

4. GIT
GIT adalah sistem pengontrol versi yang berfungsi untuk melacak dan menyimpan kode sebagai backup. GIT juga berhubungan dengan platform seperti GITHub untuk berbagi dan mengelola project secara online.
